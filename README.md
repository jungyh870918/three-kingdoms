# 삼국지 Ⅲ — 웹 오마주

코에이 「삼국지 Ⅲ」(1992, DOS) 의 화면 문법과 게임 구조를 오마주한 웹 버전입니다.
스크린샷 4장(`docs/ref/`)을 기준으로 상단 명령바 · 계절별 도트 중국지도 · 우측 시세/초상화 패널 ·
좌하단 연월 박스 · 하단 메시지창 · 군주 선택 화면 · 초상화 말풍선 이벤트를 재현했습니다.

원작의 그래픽·데이터는 일절 사용하지 않았습니다. 지도와 초상화는 모두 캔버스에서
절차적으로 그린 도트이며, 도시·무장 데이터는 사서를 참고해 직접 구성했습니다.

## 실행

의존성 없는 정적 파일입니다. `index.html` 을 브라우저로 열면 바로 시작합니다.

```bash
open index.html            # 또는
python3 -m http.server 8000   # http://localhost:8000
```

한글 도트 글꼴은 [Galmuri](https://github.com/quiple/galmuri) 를 CDN 에서 불러옵니다.
오프라인이면 시스템 고정폭 글꼴로 대체되어 글자 폭만 조금 달라집니다.

## 조작

| | |
|---|---|
| `0`~`9` | 상단 명령 선택 (0.휴양 ~ 9.기능) |
| 방향키 / `hjkl` | 목록·지도 커서 이동, 페이지 넘김 |
| `Enter` / `Space` | 결정 (무장 다중선택은 `Space` 로 토글) |
| `ESC` / 우클릭 | 취소 |
| 마우스 | 명령바·메뉴·목록·지도 도시 클릭, 전투 중 부대/타일 클릭 |
| 전투 | `Tab` 부대 선택, 빈 칸 클릭 이동, 적 클릭 공격, `Enter` 대기, `E` 차례 종료 |

한 도시의 명령을 마치려면 `0.휴양`. 모든 자기 도시를 돌면 타 세력이 움직이고 달이 넘어갑니다.
무장 한 명은 한 달에 한 번 행동하므로, 도시의 장수 수가 곧 그 달의 행동 횟수입니다.

### 손가락으로 (폰 · 태블릿)

터치 기기를 감지하면(`pointer: coarse`) 조작 목표물이 커집니다. 스테이지 1280×800 이 화면에 맞춰
축소되므로 폰에서는 배율이 0.5 안팎이 됩니다 — 그래서 **스테이지 안의 것은 넉넉히 키우고,
크기를 보장해야 하는 조작 버튼은 스테이지 밖에 실제 픽셀로** 두었습니다.

버튼은 **떠 있는 조작판이 아니라 쓰는 화면 안에** 붙습니다.

| | |
|---|---|
| 일람 (4.정보) | 패널 안에 `◀ 이전` · `다음 ▶` · `닫기`. 한 화면 8줄, 줄 높이 52px |
| 메뉴 | `닫기` 버튼. 패널 바깥을 눌러도 닫힙니다 |
| 도시 지정 | 지도를 눌러 고르고, 지도 위 버튼 줄로 `◀ 이전` · `다음 ▶` · `결정` · `닫기` |
| 무장 지정 | `닫기` (다중 선택이면 `결정` 도) |
| 숫자 입력 | 징병 인원·금액처럼 숫자를 치던 곳에는 **숫자판**이 뜹니다 (0~9 · 지움 · 최대 · 취소 · 결정) |
| 전투 | 전투 바에 `부대`(다음 부대) · `턴종료` |
| 목록 | 한 번 눌러 고르고 **다시 눌러 결정**합니다. 잘못 눌러도 실행되지 않습니다 |
| 크기 | 상단 명령바 44→72px, 짧은 메뉴의 항목 72px, 버튼은 64px |
| 지도 | 도시를 잡는 반경이 16→30px 로 넓어집니다 |

키보드·마우스 환경은 아무것도 달라지지 않습니다. `?touch=1` / `?touch=0` 으로 강제할 수 있습니다.

## 구현된 것

**시나리오 16종** 184년 황건의 난부터 255년 사마씨의 찬탈까지, 46 도시 · 무장 182명.

| | | | |
|---|---|---|---|
| 184 황건의 난 | 190 반동탁 연합 | 192 장안의 이각·곽사 | 194 군웅 할거 |
| 196 천자를 받들다 | 198 역경루의 백마 | 200 관도대전 | 207 와룡봉추 |
| 208 적벽대전 | 211 마초의 진격 | 215 한중 공방 | 219 한중왕 |
| 221 이릉대전 | 227 출사표 | 240 강유의 북벌 | 255 사마씨의 찬탈 |

시나리오마다 그 해에 살아 있는 인물만 등장한다 — 184년에는 장각·황보숭·하진이 있고,
255년에는 강유·등애·종회·사마소만 남는다.

**난이도 4종** 군주를 고른 뒤 고른다. 타 세력이 얼마나 사납게 나오는지를 한 곳에서 조절한다.

| | 먼저 쳐들어옴 | 유예 | 월 출병 | 나를 향한 군 | AI 성장 | 내 살림 | 전사 면함 |
|---|---|---|---|---|---|---|---|
| 초급 | 전력이 2.1배는 되어야 | 24개월 | 1 | 1 | 0.7배 | 1.20배 | 25% |
| **중급** | 1.7배 (나를 노릴 땐 2.2배) | 12개월 | 1 | 2 | 0.9배 | 1.00배 | 10% |
| 상급 | 1.45배 | 6개월 | 2 | 3 | 1.0배 | 0.92배 | — |
| 극악 | 1.28배 (나를 우선 노린다) | 0 | 2 | 4 | 1.15배 | 0.85배 | — |

- **유예** — 시나리오 시작 후 이 기간에는 어느 세력도 플레이어를 치지 않는다. 첫 살림을 앉힐 시간이다.
- **나를 향한 군** — 한 달에 플레이어를 향해 올 수 있는 군의 최대 수. 천하 전체를 합친 값이라
  사방에서 동시에 몰려오는 일이 구조적으로 막힌다.
- **전사 면함** — 물러난 싸움에서 무장이 죽는 대신 살아 돌아올 확률.
- AI 끼리는 이 문턱을 그대로 쓰지 않는다. 초급에서도 천하는 계속 돌아간다.

실측(16 시나리오 × 96개월): 피침공 **초급 0.06 · 중급 0.15 · 상급 0.24 · 극악 0.47회/년**.
난이도 도입 전의 고정 규칙은 0.39회/년이었으므로, 기본값 중급은 **종전의 약 1/3**이다.
`node tools/check-difficulty.js` 로 다시 잴 수 있다.

**명령 (원작 계열 그대로)**
- 1.군사 — 징병 · 훈련 · 출병 · 수송
- 2.인사 — 탐색 · 등용(재야/포로) · 이동 · 태수임명 · 포상 · 추방
- 3.외교 — 동맹 · 정전 · 동맹파기 (예물, 사자의 매력, 상대 감정으로 판정)
- 4.정보 — 도시일람 · 무장일람 · 세력일람 · 개발상황 · 자기세력 무장 · 열전 · 연표
- 5.개발 — 개간 · 치수 · 상업 · 기술 · 축성 · 순찰
- 6.계략 — 유언비어 · 매수 · 화계 · 선동 (지력 대결)
- 7.상인 — 쌀 매매, 노궁 · 강노 · 군마 구입 (시세 매월 변동)
- 8.특별 — 논공행상 · 즉위 · 인재천거 · 항복
- 9.기능 — 저장 · 불러오기(localStorage 3슬롯) · 도시 턴 종료 · 타이틀로

**전투** 16×9 격자 전술전. 평지/삼림/산/물/성벽 지형, 병종(보병·노궁·강노·기마)별 이동력·사거리·공격력,
사기와 훈련도, 성벽 방어 보정, 반격, 일기토, 포로·전사 판정, 30턴 제한(수비측 승).
공격측이 성루를 점령해도 승리합니다. AI 가 플레이어 도시를 치면 수비 측으로 직접 지휘합니다.

**사서 이벤트 (138종)** — 연의 계열 73종 + 정사 계열 32종 + 인물평 32종. 조건이 맞으면 이벤트 제목 배너와 함께 초상화·말풍선 연출이 이어진다.
한 달에 최대 두 건까지 흐르며, 굵직한 대목에서는 선택지가 나온다.

### 이벤트가 언제 터지는지 — 등급과 자물쇠

역사에서 그 일이 몇 년에 있었는지만 따지지 않는다. **어느 시나리오로 시작했는지, 지금 내 땅이 어떤
상태인지, 그 인물이 누구 밑에 있고 살아 있는지**를 함께 본다. 그래서 판을 얼마나 흔드는지에 따라
이벤트에 등급을 매기고, 등급이 높을수록 조건을 조인다.

| 등급 | 무엇이 바뀌나 | 조건 | 유예 | 간격 |
|---|---|---|---|---|
| 0 무해 | 대화 · 칭송 · 풍경 | 느슨해도 좋다 | — | — |
| 1 간접 | 충성 · 훈련 · 민심 | 느슨해도 좋다 | — | — |
| 2 재물 | 금 · 군량 · 병사 · 보물 | 보통 | 2개월 | — |
| 3 인재 | **장수가 오고 가고 주인이 바뀐다** | 까다롭게 | 8개월 | 5개월 |
| 4 생사 | **사람이 죽고 군주가 갈린다** | 가장 까다롭게 | 12개월 | 15개월 |

- **유예** — 시나리오가 시작한 뒤 이만큼 지나야 한다. 개별 조건에 구멍이 있어도 시작 직후에 판이
  뒤집히는 일은 구조적으로 막힌다.
- **간격** — 같은 등급 이상의 사건이 연달아 터지지 않는다. 한 달에 등급 3 이상은 한 건뿐이다.
- 조건문은 `Events.api` 의 기록을 볼 수 있다 — `everHeld`(한때 가졌던 땅) · `peakOf`(최대 판도) ·
  `tookFrom`(누가 누구에게서 빼앗았나) · `broken`·`declined`(세력이 무너졌나) · `serves`(누구를 섬기나) ·
  `together`(같은 성에 있나) · `captive`(포로인가) · `elapsed`(시작 후 몇 달).

**보기 — 관우가 조조에게 가는 대목.** 넉 줄이 반드시 이 순서로만 흐른다.

```
① 서주 함락, 삼형제 이산   유비가 딛고 있던 땅이 조조의 것이 되고, 유비군이 무너져야 한다
② 관우, 세 조건을 걸고 의탁   ①을 거쳤고, 관우가 유비 곁을 떠나 조조 군에 둘러싸여야 한다
③ 천리행 오관참장            관우가 조조 밑에 여섯 달 있었고, 유비가 성을 되찾아야 한다
④ 고성의 재회                관우와 장비가 한 성에서 마주쳐야 한다
```

유비가 서주에 멀쩡히 앉아 있는 동안에는 어느 시나리오에서도 ②가 서지 않는다. ③에는 반대 방향의
갈래도 있다 — 조조로 플레이해 관우의 충성을 60 이상 끌어올리면 관우는 떠나지 않는다.

같은 이유로 **군웅할거에서 제갈량을 이벤트로 얻는 것은 매우 어렵다.** 수경선생은 유비가 형주 안의
성에 있고, 관우·장비를 데리고 있고, 아직 넉 성 이하일 때만 찾아온다. 서주를 차지하고 하북으로
뻗은 유비에게는 오지 않는다. 순수한 플레이로 유비를 신야에 눌러앉히기가 어려운 만큼, 와룡을 얻는
것도 어렵다 — 의도한 균형이다.

| 시기 | 이벤트 |
|---|---|
| 반동탁 | 제후의 격문 · 사수관의 화웅(관우가 있으면 술이 식기 전에) · 호로관 삼영전여포 · 낙양 대화재와 천도 · 우물 속의 전국옥새 |

| 위진 | 고평릉의 변 |

### 정사(正史) 이벤트 32종

위의 표가 연의의 명장면이라면, 이쪽은 진수 『삼국지』와 배송지 주(注)에서 가져온 반대쪽이다.
**연의에 아예 없는 기록**과 **연의와 사실이 다른 기록**을 다루고, 연출이 끝나면 「정사에서는」
쪽지가 붙어 무엇이 다른지 적어 준다.

| | |

   ```
   node tools/check-faces.js      # 등재 누락 · 값 범위 · 혈연 아닌 인물의 골격+이목구비 중복 검사
   node tools/check-events.js 6   # 이벤트 발생 조건 — 순서 · 시작 직후 금지 · 사슬 도달 가능성
   node tools/check-difficulty.js # 난이도별 피침공 빈도 측정
   node tools/check-crash.js      # 판이 갑자기 끝나는 길이 있는지 (해산 · 실수 항복)
   tools/faces.html?trait=1       # 181명을 특징값과 함께 한 화면에서 검수
   ```

### 변환 절차

```
1. AI로 인물 초상을 만든다  →  파일 이름을 무장 이름으로 저장  (관우.png, 조조.jpg …)
2. tools/pixelize.html 을 브라우저로 열고 그림을 끌어다 놓는다
3. 색 수·디더링·대비·윤곽 슬라이더로 다듬고, ▲▼＋－ 로 얼굴 위치를 잡는다
4. [js/art.js 내려받기] → 받은 파일을 프로젝트의 js/art.js 에 덮어쓴다
```

변환기는 **두 단계 축소 → 대비·채도 보정 → 윤곽 강조 → 중앙값 분할로 색 줄이기 →
베이어 4×4 디더링 → 금색 액자 합성** 순서로 처리합니다.
「게임 팔레트로 맞추기」를 켜면 UI와 같은 34색 안으로 억지로 밀어 넣어 화면 톤이 완전히 통일됩니다.
아래쪽에 **아직 삽화가 없는 무장 목록**이 계속 표시되므로 181명을 채워 나가기 좋습니다.

### 원본 이미지 권장 규격

- 정면 흉상, 어깨까지. 얼굴이 화면의 60~70%
- 512×640 이상, 배경은 단색이나 단순한 무늬 (복잡하면 축소할 때 얼굴을 잡아먹습니다)
- 인물마다 화풍·조명·구도를 같게 (프롬프트를 고정하고 인물 설명만 바꾸는 방식)
- 관모·투구·수염 같은 실루엣 요소를 크게 — 95×110으로 줄이면 이것만 남습니다

## 원작과 다른 점

- 도시 번호·좌표·인접 관계, 무장 능력치는 원작 데이터가 아니라 재구성한 값입니다.
- 후기 시나리오의 군주(240년 사마의, 255년 육항 등)는 게임 편의를 위해 실권자를 세운 것입니다.
- 파란 번호(47~67)의 관문·항구는 지도 표식이며 별도 거점으로 동작하지 않습니다.
- 상성·야망·일족 관계, 화공/수공 같은 전장 계략은 넣지 않았습니다.
- 등장·사망 연도는 사서를 참고한 근사치이며, 전투에서 죽으면 그보다 일찍 사라집니다.
- 시세 패널의 `쌀팜`은 구입가, `쌀삼`은 매도가로 처리했습니다(차익 거래가 생기지 않도록).
