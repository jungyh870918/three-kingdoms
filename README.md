# 삼국지 Ⅲ — 웹 오마주

코에이 「삼국지 Ⅲ」(1992, DOS) 의 화면 문법과 게임 구조를 오마주한 웹 버전입니다.
스크린샷 4장(`docs/ref/`)을 기준으로 상단 명령바 · 계절별 도트 중국지도 · 우측 시세/초상화 패널 ·
좌하단 연월 박스 · 하단 메시지창 · 군주 선택 화면 · 초상화 말풍선 이벤트를 재현했습니다.

원작의 그래픽·데이터는 일절 사용하지 않았습니다. 지도와 초상화는 모두 캔버스에서
절차적으로 그린 도트이며, 도시·무장 데이터는 사서를 참고해 직접 구성했습니다.

## 실행

의존성 없는 정적 파일입니다. `index.html` 을 브라우저로 열면 바로 시작합니다.

```bash
open index.html            # 또는
python3 -m http.server 8000   # http://localhost:8000
```

한글 도트 글꼴은 [Galmuri](https://github.com/quiple/galmuri) 를 CDN 에서 불러옵니다.
오프라인이면 시스템 고정폭 글꼴로 대체되어 글자 폭만 조금 달라집니다.

## 조작

| | |
|---|---|
| `0`~`9` | 상단 명령 선택 (0.휴양 ~ 9.기능) |
| 방향키 / `hjkl` | 목록·지도 커서 이동, 페이지 넘김 |
| `Enter` / `Space` | 결정 (무장 다중선택은 `Space` 로 토글) |
| `ESC` / 우클릭 | 취소 |
| 마우스 | 명령바·메뉴·목록·지도 도시 클릭, 전투 중 부대/타일 클릭 |
| 전투 | `Tab` 부대 선택, 빈 칸 클릭 이동, 적 클릭 공격, `Enter` 대기, `E` 차례 종료 |

한 도시의 명령을 마치려면 `0.휴양`. 모든 자기 도시를 돌면 타 세력이 움직이고 달이 넘어갑니다.
무장 한 명은 한 달에 한 번 행동하므로, 도시의 장수 수가 곧 그 달의 행동 횟수입니다.

## 구현된 것

**시나리오** 190년 반동탁 연합 / 194년 군웅 할거 — 46 도시, 20·16 세력, 무장 150여 명.

**명령 (원작 계열 그대로)**
- 1.군사 — 징병 · 훈련 · 출병 · 수송
- 2.인사 — 탐색 · 등용(재야/포로) · 이동 · 태수임명 · 포상 · 추방
- 3.외교 — 동맹 · 정전 · 동맹파기 (예물, 사자의 매력, 상대 감정으로 판정)
- 4.정보 — 도시일람 · 무장일람 · 세력일람 · 개발상황 · 자기세력 무장
- 5.개발 — 개간 · 치수 · 상업 · 기술 · 축성 · 순찰
- 6.계략 — 유언비어 · 매수 · 화계 · 선동 (지력 대결)
- 7.상인 — 쌀 매매, 노궁 · 강노 · 군마 구입 (시세 매월 변동)
- 8.특별 — 논공행상 · 즉위 · 인재천거 · 항복
- 9.기능 — 저장 · 불러오기(localStorage 3슬롯) · 도시 턴 종료 · 타이틀로

**전투** 16×9 격자 전술전. 평지/삼림/산/물/성벽 지형, 병종(보병·노궁·강노·기마)별 이동력·사거리·공격력,
사기와 훈련도, 성벽 방어 보정, 반격, 일기토, 포로·전사 판정, 30턴 제한(수비측 승).
공격측이 성루를 점령해도 승리합니다. AI 가 플레이어 도시를 치면 수비 측으로 직접 지휘합니다.

**월말 처리** 군량 소비, 3·9월 금 수입, 4·9월 수확, 인구 증감, 수해·역병·가뭄,
민심 이반에 따른 봉기, 충성 낮은 무장의 이탈, 태수의 모반 → 독립 군주 등장(원작 이벤트 오마주),
사마휘의 조언 말풍선, 시세 변동.

**AI** 세력별 내정(순찰·개간·상업·치수·축성·기술·징병·훈련·무기 구입·쌀 매매), 강자에 붙는 외교,
전력 비교 후 출병. AI 대 AI 전투는 자동 판정합니다.

## 파일

```
index.html      화면 골격
css/style.css   도트 UI (1280x800 스테이지를 화면 크기에 맞춰 확대)
js/data.js      도시 46 · 경로 · 관문 · 무장 150여 · 시나리오
js/map.js       지형 절차 생성(계절 4종 캐시) + 도시 마커
js/portrait.js  이름 해시로 만드는 도트 초상화
js/ui.js        패널·메뉴·입력(Promise 기반) + 지도 렌더 루프
js/battle.js    격자 전투
js/game.js      상태 · 명령 · AI · 월말 처리
js/main.js      타이틀 → 시나리오 → 군주 선택 → 본편
tools/faces.html  전체 초상화 확인용 페이지
docs/ref/       참고한 원작 스크린샷
```

## 원작과 다른 점

- 도시 번호·좌표·인접 관계, 무장 능력치는 원작 데이터가 아니라 재구성한 값입니다.
- 파란 번호(47~67)의 관문·항구는 지도 표식이며 별도 거점으로 동작하지 않습니다.
- 상성·야망·수명·일족, 화공/수공 같은 전장 계략, 이민족 세력, 옥새 등은 넣지 않았습니다.
- 시세 패널의 `쌀팜`은 구입가, `쌀삼`은 매도가로 처리했습니다(차익 거래가 생기지 않도록).
