# 삼국지 Ⅲ — 웹 오마주

코에이 「삼국지 Ⅲ」(1992, DOS) 의 화면 문법과 게임 구조를 오마주한 웹 버전입니다.
스크린샷 4장(`docs/ref/`)을 기준으로 상단 명령바 · 계절별 도트 중국지도 · 우측 시세/초상화 패널 ·
좌하단 연월 박스 · 하단 메시지창 · 군주 선택 화면 · 초상화 말풍선 이벤트를 재현했습니다.

원작의 그래픽·데이터는 일절 사용하지 않았습니다. 지도와 초상화는 모두 캔버스에서
절차적으로 그린 도트이며, 도시·무장 데이터는 사서를 참고해 직접 구성했습니다.

## 실행

의존성 없는 정적 파일입니다. `index.html` 을 브라우저로 열면 바로 시작합니다.

```bash
open index.html            # 또는
python3 -m http.server 8000   # http://localhost:8000
```

한글 도트 글꼴은 [Galmuri](https://github.com/quiple/galmuri) 를 CDN 에서 불러옵니다.
오프라인이면 시스템 고정폭 글꼴로 대체되어 글자 폭만 조금 달라집니다.

## 조작

| | |
|---|---|
| `0`~`9` | 상단 명령 선택 (0.휴양 ~ 9.기능) |
| 방향키 / `hjkl` | 목록·지도 커서 이동, 페이지 넘김 |
| `Enter` / `Space` | 결정 (무장 다중선택은 `Space` 로 토글) |
| `ESC` / 우클릭 | 취소 |
| 마우스 | 명령바·메뉴·목록·지도 도시 클릭, 전투 중 부대/타일 클릭 |
| 전투 | `Tab` 부대 선택, 빈 칸 클릭 이동, 적 클릭 공격, `Enter` 대기, `E` 차례 종료 |

한 도시의 명령을 마치려면 `0.휴양`. 모든 자기 도시를 돌면 타 세력이 움직이고 달이 넘어갑니다.
무장 한 명은 한 달에 한 번 행동하므로, 도시의 장수 수가 곧 그 달의 행동 횟수입니다.

시나리오마다 그 해에 살아 있는 인물만 등장한다 — 184년에는 장각·황보숭·하진이 있고,
255년에는 강유·등애·종회·사마소만 남는다.

**명령 (원작 계열 그대로)**
- 1.군사 — 징병 · 훈련 · 출병 · 수송
- 2.인사 — 탐색 · 등용(재야/포로) · 이동 · 태수임명 · 포상 · 추방
- 3.외교 — 동맹 · 정전 · 동맹파기 (예물, 사자의 매력, 상대 감정으로 판정)
- 4.정보 — 도시일람 · 무장일람 · 세력일람 · 개발상황 · 자기세력 무장 · 열전 · 연표
- 5.개발 — 개간 · 치수 · 상업 · 기술 · 축성 · 순찰
- 6.계략 — 유언비어 · 매수 · 화계 · 선동 (지력 대결)
- 7.상인 — 쌀 매매, 노궁 · 강노 · 군마 구입 (시세 매월 변동)
- 8.특별 — 논공행상 · 즉위 · 인재천거 · 항복
- 9.기능 — 저장 · 불러오기(localStorage 3슬롯) · 도시 턴 종료 · 타이틀로

**전투** 16×9 격자 전술전. 평지/삼림/산/물/성벽 지형, 병종(보병·노궁·강노·기마)별 이동력·사거리·공격력,
사기와 훈련도, 성벽 방어 보정, 반격, 일기토, 포로·전사 판정, 30턴 제한(수비측 승).
공격측이 성루를 점령해도 승리합니다. AI 가 플레이어 도시를 치면 수비 측으로 직접 지휘합니다.

**열전과 실록** 무장 182명 모두에게 자(字)와 열전문이 있고,
그중 70여 명에게는 「정사에서는」 항목이 따로 붙는다 — 연의와 정사의 차이, 흔한 오해를 적어 두었다.

> **조운** — 정사의 조운은 오래도록 근위·호위 성격의 자리에 있었고 대군을 홀로 지휘한 기록은 드물다.
> 칠진칠출도 오호대장군도 연의의 설정이다. 진짜 미덕은 무용보다 절제였다.
> **사섭** — 교주(지금의 광서·북베트남)를 사십 년 다스린 명문 사족. 중원의 학자를 거두어 남방에 학문을 심었고,
> 베트남에서는 지금도 「사왕(士王)」으로 사당에 모신다.
> **공손찬** — 백마의종은 오환이 "백마장사를 피하라" 이르던 정예 기병이었다. 계교에서 국의의 강노에 부서졌다.
> **장비** — 사대부를 존경하고 병졸에게 가혹했다(관우는 정반대였다). 장합을 지형으로 완파한 지장이다.
> **마초** — 그가 먼저 거병했기에 아버지 마등 일족이 몰살당했다. 촉에서는 실권 없이 47세에 병사했다.
> **관우** — 진수는 "강하고 자부심이 지나쳐 스스로를 그르쳤다"고 적었다.
> **노숙** — 우유부단한 호인이 아니라, 손유동맹을 설계하고 끝까지 지킨 친유비 노선의 전략가였다.

정보 > 열전에서 이름으로 찾아보거나 무장일람에서 Enter. 사건은 정보 > 연표에 연월과 함께 쌓인다.

**월말 처리** 군량 소비, 3·9월 금 수입, 4·9월 수확, 인구 증감, 수해·역병·가뭄,
민심 이반에 따른 봉기, 충성 낮은 무장의 이탈, 태수의 모반 → 독립 군주 등장(원작 이벤트 오마주),
사마휘의 조언 말풍선, 시세 변동.

**AI** 세력별 내정(순찰·개간·상업·치수·축성·기술·징병·훈련·무기 구입·쌀 매매), 강자에 붙는 외교,
전력 비교 후 출병. AI 대 AI 전투는 자동 판정합니다.

## 인물 삽화 만들기

초상화는 두 겹입니다.

1. **`js/art.js`** — 준비된 삽화(95×110 도트 + 금색 액자)를 이름별로 담아 둡니다. 있으면 이것을 씁니다.
2. **없으면 자동 생성** — 이름 해시로 얼굴·수염·관을 조합해 그립니다.
   `js/faces.js` 에 특징을 적어 둔 인물(관우의 홍안·장수염, 장비의 흑면·고리눈, 유비의 면류관·큰 귀,
   제갈량의 윤건·백우선, 하후돈의 안대 등 30여 명)은 그 값대로 그려집니다.

### 변환 절차

```
1. AI로 인물 초상을 만든다  →  파일 이름을 무장 이름으로 저장  (관우.png, 조조.jpg …)
2. tools/pixelize.html 을 브라우저로 열고 그림을 끌어다 놓는다
3. 색 수·디더링·대비·윤곽 슬라이더로 다듬고, ▲▼＋－ 로 얼굴 위치를 잡는다
4. [js/art.js 내려받기] → 받은 파일을 프로젝트의 js/art.js 에 덮어쓴다
```

변환기는 **두 단계 축소 → 대비·채도 보정 → 윤곽 강조 → 중앙값 분할로 색 줄이기 →
베이어 4×4 디더링 → 금색 액자 합성** 순서로 처리합니다.
「게임 팔레트로 맞추기」를 켜면 UI와 같은 34색 안으로 억지로 밀어 넣어 화면 톤이 완전히 통일됩니다.
아래쪽에 **아직 삽화가 없는 무장 목록**이 계속 표시되므로 181명을 채워 나가기 좋습니다.

### 원본 이미지 권장 규격

- 정면 흉상, 어깨까지. 얼굴이 화면의 60~70%
- 512×640 이상, 배경은 단색이나 단순한 무늬 (복잡하면 축소할 때 얼굴을 잡아먹습니다)
- 인물마다 화풍·조명·구도를 같게 (프롬프트를 고정하고 인물 설명만 바꾸는 방식)
- 관모·투구·수염 같은 실루엣 요소를 크게 — 95×110으로 줄이면 이것만 남습니다

## 원작과 다른 점

- 도시 번호·좌표·인접 관계, 무장 능력치는 원작 데이터가 아니라 재구성한 값입니다.
- 후기 시나리오의 군주(240년 사마의, 255년 육항 등)는 게임 편의를 위해 실권자를 세운 것입니다.
- 파란 번호(47~67)의 관문·항구는 지도 표식이며 별도 거점으로 동작하지 않습니다.
- 상성·야망·일족 관계, 화공/수공 같은 전장 계략은 넣지 않았습니다.
- 등장·사망 연도는 사서를 참고한 근사치이며, 전투에서 죽으면 그보다 일찍 사라집니다.
- 시세 패널의 `쌀팜`은 구입가, `쌀삼`은 매도가로 처리했습니다(차익 거래가 생기지 않도록).
